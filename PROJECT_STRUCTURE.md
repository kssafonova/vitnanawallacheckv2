# Structure

- `/index.php` — homepage
- `/catalog/` — 5 base product cards
- `/catalog/{model}/` — product detail with color + direction variations
- `/calculator/` — project calculator
- `/systems/`, `/hs-portal/`, `/fs-portal/` — system pages
- `/projects/`, `/company/`, `/faq/`, `/contact/` — supporting pages
- `/config/catalog.php` — product source of truth
- `/config/merchant.php` — future merchant/YML fields (blank)
- `/config/site.php` — anonymous project config, SEO disabled
