# PORTAL SYSTEMS — HS Portal Canvas Demo

Готовый автономный интерактивный блок для HS-портала (подъёмно-сдвижной системы).

## Файлы

- `index.html` — демо-страница
- `styles.css` — стили блока
- `hs-portal.js` — Canvas-анимация

## Что показывает анимация

HS-портал открывается не как обычная раздвижка:
1. створка сначала чуть приподнимается над нижним уплотнением;
2. затем плавно сдвигается вправо по направляющим;
3. при закрытии возвращается назад и опускается в герметичное положение.

В анимации это отражено:
- есть лёгкий lift-эффект в начале хода;
- затем активная створка с ручкой уходит вправо;
- остаётся открытый проём слева.

## Что умеет

- mobile-first структура;
- плавное открытие / закрытие;
- управление ползунком;
- управление мышью или пальцем прямо по Canvas;
- `prefers-reduced-motion`;
- без библиотек и внешних зависимостей;
- адаптивное Retina-отрисовывание.

## Как запустить

Просто откройте `index.html` в браузере.

## Как встроить в PORTAL SYSTEMS

1. перенесите HTML секции `.hs-demo` в нужный PHP-шаблон;
2. подключите `styles.css`;
3. подключите `hs-portal.js` перед `</body>` или через общий footer.

Пример:

```html
<link rel="stylesheet" href="/assets/css/hs-portal.css">
<script src="/assets/js/hs-portal.js" defer></script>
```
